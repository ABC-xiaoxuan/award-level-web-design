    01 / 工作方式

    不是一次生成，
    而是一轮一轮改出来的。

    评委看的是一个清晰的概念被执行到每个细节，而不是特效堆得多不多。

    1. 01

      先定概念

      先写三个方向再选一个，把概念翻译成字体、色彩、版式、动效、文案和"签名时刻"，先写文案再定版式。

      避开 AI 模板脸
    2. 02

      守住底线实现

      设计令牌、只动 transform/opacity、完整交互状态、AA 对比度、减弱动效偏好。

      375 → 1920 四档宽度
    3. 03

      截图—打分—修改

      截图加眯眼图，九个维度按锚点打分、附证据，再由只看截图的独立评委复评。无红线、没有维度低于 8、加权总分 ≥ 8.5 才停。

      脚本审计 + 2–3 轮
    01排版02留白03视觉层级04色彩05动效06微交互07响应式08原创性09内容

    设计 40% · 可用性 30% · 创意 20% · 内容 10%，权重来自 Awwwards 评审体系

    有没有用，盲评说了算

    同一个需求，各做一版不用 skill 的和用 skill 的，随机编号后交给只看截图的评委打分。

    建筑事务所
    6.55→8.00
    技术大会
    7.03→7.95

    差距最大的是原创性：对照组的概念只停留在首屏。目前每个需求只跑了一次，完整结果与局限。

    03 / 安装

    一行命令，
    装进你的 AI 助手。

    装好后不用特意调用：做落地页、官网、作品集，或者说"要高级感"时会自动启用。

    npx 推荐

    支持 Claude Code、Codex、Cursor 等 30+ 工具，自动放进对应目录。

    npx skills add \ ABC-xiaoxuan/award-level-web-design -g

    Claude Code 插件 Plugin

    在 Claude Code 里依次输入这两行。

    /plugin marketplace add ABC-xiaoxuan/award-level-web-design /plugin install award-level-web-design@award-level-web-design

    手动复制 Manual

    把 skills/award-level-web-design/ 整个文件夹复制过去。

    Claude Code → ~/.claude/skills/ Codex → ~/.agents/skills/
