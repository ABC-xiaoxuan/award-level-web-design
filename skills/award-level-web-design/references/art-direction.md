# 美术方向与叙事结构

SKILL.md 1.1 要求写出三个方向。这份参考提供可选的"方向"和"结构"：三个方向应当来自**不同的美术方向**，每个方向再配一种叙事结构。

结构参考了 [SandroHub013/awwwards-skill](https://github.com/SandroHub013/awwwards-skill)（MIT）的 `02-concept.md`，按中文页面和单页落地页的情况重新整理，并补充了东方编辑、竖排等方向。

## 1. 美术方向

选一个，然后坚持到底。混用方向，是"做得还行但很平淡"最常见的原因。

| 方向 | 特征 | 动效性格 | 风险 |
| --- | --- | --- | --- |
| **编辑 Editorial** | 大号衬线或怪诞体标题，严格网格，宽边距，细线和图注，克制的颜色，图片像印刷品一样处理 | 细微：遮罩揭示、文字过渡 | 变成杂志模板。需要至少一处出人意料的结构变化 |
| **东方编辑** | 宋体或楷体标题，竖排章节名或引文，大面积留白，印章式红色点缀，纸张底色 | 缓慢：淡入、墨迹般的展开 | 落入"中国风"俗套（祥云、水墨笔刷、毛笔字铺满）。只用一两处，而且要服务于内容 |
| **粗野 Brutalist** | 系统字体或等宽字体，高对比，暴露结构，硬边，无阴影，有控制的"丑" | 瞬间、机械，不用缓动 | 间距节奏不完美时看起来像没做完。粗野风格对对齐的要求反而更高 |
| **动态排版 Kinetic** | 文字本身就是主视觉，滚动即编排 | 持续、有节奏 | 晕动、难以阅读，对 reduced-motion 和性能要求最高 |
| **静奢 Quiet luxury** | 元素极少，巨大留白，一个强调色，缓慢淡入，低饱和色板，排版无可挑剔 | 很慢，很少 | 留白却没有足够的工艺，就像没做完的页面 |
| **技术图纸 Technical** | 制图网格、坐标、尺寸标注、编号、等宽字体、细线 | 精确：线条绘制、数值滚动 | 信息过密，变成仪表盘 |
| **复古技术 Retro-tech** | 终端风格、抖动、ASCII、像素字体、系统界面仿制 | 步进，不用缓动 | 用怀旧代替想法 |
| **有机材质 Organic** | 颗粒、纸张、织物、手作元素、不完美的网格 | 有重量感和惯性 | 纹理堆砌、对比度不足 |

三个方向要来自不同的行。例如为咖啡店写方向时，"编辑：烘焙记录卡""技术图纸：烘焙曲线仪表""有机材质：牛皮纸包装"是三个真正不同的方向；"暖色编辑风""冷色编辑风""深色编辑风"只是同一个方向换了配色。

## 2. 叙事结构

获奖网站几乎都有作者安排好的阅读顺序，而不是一堆区块从上往下堆。

| 结构 | 顺序 | 适合 |
| --- | --- | --- |
| **揭示** | 首屏宣言 → 逐步展开想法 → 证据 → 邀请行动 | 品牌、产品、活动 |
| **旅程** | 滚动推进一个连续变化（一条时间线、一个过程、一段路） | 有工艺流程或故事的品牌 |
| **索引** | 用一个浏览系统组织大量条目，系统本身就是创意 | 作品集、档案、事务所 |
| **工具** | 页面本身是一个可以玩的工具（演示、配置器、生成器） | 软件产品、技术活动。创意上限最高，可用性风险也最高 |

## 3. 节拍表

确定结构后，先写节拍表再写代码。每个节拍对应一屏左右的内容，写清楚两件事：这一屏的目的，以及这一屏**唯一的**视觉事件。落地页一般 5–9 个节拍，更多需要理由。

```
节拍  目的                     视觉事件
1     一句话说清是谁、卖什么     超大标题错位构图
2     证明不是空话               一条自动绘制的烘焙曲线（签名时刻）
3     具体有什么                 豆单索引，悬停显示风味
4     怎么做到的                 四步流程，时间轴展开
5     有人认可                   一句引文，竖排署名
6     现在行动                   订阅表单，深色收尾
```

每个节拍只有一个视觉事件。如果一屏里同时有三个东西在动，或者每一屏都用同一种淡入，节拍表就是在提醒你：节奏没有设计过。
